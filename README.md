# おうち買い出しレシート品目ごとの個人別カンタン立替算

家族や同居人とのまとめ買いレシートから、個人の購入品目をタップするだけで各自の支払額を瞬時に分けるツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/receipt-item-matcher/）。
2. 画面の指示に従って操作します。
